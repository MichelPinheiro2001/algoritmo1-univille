# 📚 Algoritmo I - Univille

Repositório oficial para entrega e versionamento dos códigos desenvolvidos nas aulas de **Algoritmo I** da [Univille](https://www.univille.br/), ministradas pela professora **Sabrina Boing Moreira**.

---

## 🛠️ Ferramentas Utilizadas

* **[VisuAlg Web](https://visualgweb.com.br/)** - Editor e interpretador online de Portugol utilizado para desenvolver os algoritmos durante as aulas.
* **VS Code** e **Git** - Utilizados para gerenciar o versionamento e realizar os commits e envios para o GitHub.

---

## 📂 Organização do Repositório

* **`/PORTUGOL`** - Pasta principal que centraliza todos os arquivos e listas de exercícios desenvolvidos na disciplina para avaliação e revisão da professora.

*Conforme a matéria for evoluindo e novos conteúdos forem abordados, novas pastas e estruturas poderão ser adicionadas a este repositório.*

---

## 🚀 Como Executar

1. Acesse o **[VisuAlg Web](https://visualgweb.com.br/)**.
2. Abra o arquivo desejado dentro da pasta `PORTUGOL`.
3. Copie o código, cole no editor web e execute.
